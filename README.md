# My first 2D Game

My first ever Game made in Godot, featuring realistic physics

## Core Features

* **Custom Fluid Dynamics & Drag:** Realistic Linear Drag, Quadratic Drag, Dampening, Buoyancy
* **Planetary Gravity & Theoretical Core Inversion:** Continuous gravity calculations
* **Movement Abilities:** Jumping, double jumping, horizontal dashes and downward stomping

## Tech Stack

* **Engine:** Godot 4.X
* **Language:** GDScript
